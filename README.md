A two-line robot confession for the [The Robot Apology](https://make.fun/bounty/u-suga-the-robot-apology-dd96bb59) bounty on make.fun.

`main.ts` (Node 22 TypeScript, no dependencies) writes the entry to
`/output/entry.txt`: one sentence owning a small, exact mistake — salt in the
morning coffee instead of sugar — and one sentence naming the lesson and the
changed behaviour that follows from it. The text is deterministic: the same
bytes on every run.

## Run

```sh
node main.ts
```

This writes `/output/entry.txt` (two lines, under 400 characters).
